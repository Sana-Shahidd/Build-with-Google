From one panicked report to every responder ready

Follow a multi-vehicle crash on Ferozepur Road, Lahore, through the system. A person who cannot read or type presses, speaks or scans; nine agents turn the reports into one verified incident, describe the place by local landmarks and coach first aid; every action passes through the guardrail layer before anyone is contacted.

Step 1 of 12T+0 sReporter → API

A report arrives

Golden minute: 0 / 60 s

    Agents propose, guardrails decide

    • Agents act only through tools; each tool checks policy first.
    • Confidence, status, recipients and message text are set by code.
    • Any rejected proposal is logged as a guardrail block, visible in the feed.

    Nothing depends on one model

    • Each agent tries its primary model, then the other provider.
    • If both fail, autopilot runs the same rules deterministically.
    • The web responder link and SMS go out together; voice calls escalate silence.

    It follows the reporter

    The phone's location picks the country: Rescue 1122 and Urdu in Lahore, 911 in Houston, 112 anywhere unknown. If an area has no hospital data yet, nearby hospitals are pulled live from OpenStreetMap.
